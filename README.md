# 🌌 Nebula Drive - Cosmic Cloud Storage

Nebula Drive is a modern, full-stack cloud storage solution built with **Next.js 14**, **Firebase**, and **Clerk**.

## 🚀 Features
* **Secure Auth:** Powered by Clerk for seamless login/signup.
* **File Management:** Upload and store files in the cloud via Firebase Storage.
* **Real-time Dashboard:** View and manage your files in a clean, responsive table.
* **Delete Functionality:** Safely remove files from both storage and database.
* **Theming:** Dark and light mode support for a cosmic experience.

## 🛠️ Tech Stack
* **Framework:** Next.js (App Router)
* **Authentication:** Clerk
* **Database/Storage:** Firebase (Firestore & Storage)
* **Styling:** Tailwind CSS & Shadcn/UI

## ⚙️ Setup
1. Clone the repo.
2. Install dependencies: `npm install`
3. Add your `.env.local` keys for Clerk and Firebase.
4. Run locally: `npm run dev`
